# EDrive Pakistan

## Pakistan Ride-Hailing & Taxi Platform

**EDrive Pakistan** is a Pakistan-focused ride-hailing and taxi platform, initially focused on Lahore.

### Founder & Owner

**Muhammad Awais**

### Location

Lahore, Punjab, Pakistan

## About EDrive Pakistan

EDrive Pakistan is being developed to provide a simple and convenient ride-booking experience for passengers and drivers in Pakistan.

### Main Features

- Passenger ride booking
- Driver registration and verification
- Real-time ride status
- Driver ride acceptance
- Fare calculation
- Live location and Google Maps integration
- Driver and passenger communication
- Admin management system
- Ride history
- Safety features
- Cash payment support

## Platform

EDrive Pakistan is designed for:

- Android
- iOS
- Web Admin Panel

## Vision

To build a reliable, user-friendly and Pakistan-focused ride-hailing platform.
